# Data Science Tasks – Global Superstore

## Project Overview
This repository contains three data science tasks completed using the Global Superstore dataset. The tasks cover data cleaning, exploratory data analysis (EDA), and sales prediction using Python.

## Tasks

### Task 1: Data Cleaning
- Cleaned and prepared the dataset for analysis.
- Handled data quality issues where applicable.
- Saved the cleaned dataset for further analysis.

### Task 2: Exploratory Data Analysis (EDA)
- Explored the dataset to understand sales and business trends.
- Analyzed data patterns using Python.
- Used visualizations to support insights, where applicable.

### Task 3: Sales Prediction
- Worked on a sales prediction task using the dataset.
- Prepared data for predictive analysis.
- Explored a machine learning approach for sales forecasting, where applicable.
